# Electricity Consumption and Bill Analysis Using R

## Project Overview
The **Electricity Consumption and Bill Analysis Using R** project focuses on analyzing electricity usage and calculating electricity bills using R programming. It helps users understand their monthly electricity consumption, monitor billing patterns, and identify changes in electricity usage through data analysis and visualization.

The project uses R programming for data processing, calculations, and graphical representation of electricity consumption.

## Objectives
- To analyze monthly electricity consumption.
- To calculate electricity bills based on units consumed.
- To identify high and low electricity consumption periods.
- To visualize electricity usage using graphs and charts.
- To understand consumption patterns and provide useful observations.

## Features
- Electricity consumption data creation and loading.
- Monthly electricity usage analysis.
- Automatic electricity bill calculation.
- Calculation of total and average consumption.
- Identification of maximum and minimum consumption.
- Data visualization using charts and graphs.
- Analysis of electricity consumption trends.

## Technologies Used
- **Programming Language:** R
- **IDE:** RStudio
- **Libraries:** ggplot2, dplyr
- **Data Format:** CSV

## How to Run the Project
1. Install R and RStudio.
2. Download or clone this repository.
3. Open the project folder in RStudio.
4. Install the required packages:

```r
install.packages("ggplot2")
install.packages("dplyr")
```

5. Open `electricity_analysis.R`.
6. Run the script to perform electricity consumption and bill analysis.
